# Микросервис Калькулятор

## Назначение
Сервис для предварительного расчета кредитных предложений и полного скоринга кредитных заявок.

## Функциональность
- **Прескоринг**: генерация 4 кредитных предложений на основе комбинаций страховки и зарплатного клиента
- **Скоринг данных**: валидация и оценка клиента по множеству параметров
- **Расчет кредита**: ежемесячный платеж, ПСК, график платежей

## Технологии
- Java 21
- Spring Boot 3.5.11
- JUnit / Mockito
- Lombok
- Swagger (springdoc)
